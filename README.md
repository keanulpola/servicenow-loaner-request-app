# ServiceNow Loaner Request App

A scoped ServiceNow application for managing equipment loan requests.

I built this application during ServiceNow application development training to practice configuring, scripting, automating, securing,
and testing an application on the Now Platform.

## Features

- Create and manage loaner requests
- Track open, unassigned, and closed requests
- User and admin roles with access controls
- Validate request start and end dates
- Automatically populate request information based on user and configuration data
- Create and manage loaner tasks
- Configure pickup, return, and overdue reminders
- Trigger events and email notifications
- Retrieve data through REST integrations
- Display requestor locations using geocoding data
- Test loaner request creation with ServiceNow Automated Test Framework

## ServiceNow Components Used

- Scoped Applications
- Custom Tables
- Application Modules
- ACLs and Roles
- Business Rules
- Client Scripts
- UI Policies
- Script Includes
- GlideRecord
- System Properties
- Events and Email Notifications
- Flow Designer
- REST Messages and RESTMessageV2
- Automated Test Framework
- Source Control

## Project Structure

This repository contains source-controlled ServiceNow application files and XML records. The application is designed to run inside
a ServiceNow instance rather than as a standalone application.

## Project Background

This project was completed as part of hands-on ServiceNow application development training. It gave me experience working with platform 
configuration, server-side and client-side scripting, security, automation, integrations, and application testing.
